화면 종류

홈 화면

연결 상태, 오늘 많이 쓴 앱, 카테고리별 주의 추이를 보여주고 중앙 측정 버튼으로 측정을 시작한다.

오버레이 화면

영상앱 또는 게임앱 위에 모드 버튼이 뜬다. 주의 상태는 모드 버튼 옆에 잠깐 나타났다가 사라진다.

앱 설정 화면

프로필에서 자세 오버레이 시작, 모드별 카메라 사용, 알람, 측정 기준을 설정한다.

리포트 화면

오늘, 주간, 월간 탭에서 총 사용시간과 총 주의 횟수를 확인하고 카테고리별 앱 상세로 들어간다.
